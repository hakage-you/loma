## 2. 直したもの（優先度順）

### 優先度1: 軽量化

**`useMedia` が2回呼ばれていた。**
`App` が言語設定のためだけに呼び、`AppContent` が本体としてもう一度呼んでいた。
`useMedia` は state・`batch_progress` の購読・起動時の取得を抱えているので、
2回呼べば全部が2組になる。`MediaContext` を作って1つにした。

**解析中の再取得が一度も走らないことがあった。**
1秒に間引くつもりの実装が**トレーリングのデバウンス**で、進捗が1秒より速く届くと
タイマーが張り直され続けて発火しなかった。登録フェーズ（5件ごと）や解析の速い
モデルがこれに当たり、**解析が終わるまでギャラリーが更新されない**。
間引き（1秒に最大1回、ただし必ず走る）に直した。

**タグ絞り込みの入力が1打鍵ごとに 179ms ブロックしていた。**
一覧の作り直しが入力と同じ同期の描画に乗っていた。`useDeferredValue` で
入力の表示を先に返すようにした。**最悪値（約250ms）は残っている** ——
200行の作り直し自体の代償で、消すには一覧の仮想化が要る（→ plan P-2）。

**全画面のログ表示が 8MB を一度にヒープへ載せていた。**
`onGetLogs()` を引数なしで呼んでおり、バックエンドの既定が返っていた。
JS 文字列は UTF-16 なので約16MB。2MB に制限し、DOM に出す行数も末尾2,000行で
打ち切って、切ったことを件数つきで画面に出す。

### 優先度2: 安定化

**関連タグの提案が実行ごとに入れ替わっていた。**
`connected_components` が `HashMap` をそのまま走査していたため、BFS の開始点が
実行ごとに変わっていた。実データ（提案742件）で再現し、修正を外すと落ちる
テストを実DB・単体の両方に置いた。

**ログにローテーションが無く、無制限に伸びていた。**
実際に 5.2MB まで伸びたものを手で退避した記録が残っていた。
5MB で世代を送り、本体+3世代（最大 20MB）で頭打ちにした。

**押した操作の失敗が画面に出ないものが6つあった。**
一時停止・再開・中止・フォルダの登録解除・ログのクリア・VRAM の解放は
`console.error` だけで、**押しても何も起きないように見えていた**。

### 優先度3: 一貫性

**画面ごとに英語のままだった表示を日本語へ揃えた。**
`FolderManagerModal` はほぼ全部、`LogViewerModal` は `t()` が1箇所も無かった。
ロケールにキーが定義済みで一度も使われていないものもあった。
`check:locale` に**未使用キーの検出**を足し、旧UIの残骸12件を削除した。

**フォルダの登録解除に確認が無かった。**
この操作はフォルダ配下のメディアの行・タグ・サムネイルを消す。同じモーダルの
「全メディア再解析」は確認を挟むのに、**より戻せないこちらには無かった**。

**押せなくしたボタンの16箇所が理由を出していなかった。**
`useExclusiveGuard` の doc コメントが「理由を出さないとボタンが壊れたように
見える」と書いているのに、23箇所のうち16箇所で出していなかった。
`check:exclusive` が静的にも見るようにした。

**同じ文字が別の意味で使われていた。**
削除の確認を取り消すボタンが「閉じる」で、モーダルを閉じる×と同じだった。
「モーダルを閉じる＝閉じる／操作をやめる＝キャンセル」に揃えた。

## 3. テストの土台

着手時、**mock モードの e2e は「押せた／落ちなかった」しか見ていなかった。**
`src/mocks/core.ts` に handler が無いコマンドは `undefined` を返すだけで例外に
ならないため、画面がバックエンドの応答を使う経路は一度も走らないまま緑になる。

- 不足していた **22コマンド**の handler を実装した
- 提案3方式は `() => []` を返すだけで、**AI提案タブが一度も描画されなかった**
- 一括処理の完了イベントを出すようにした。実物は必ず送る。出さないと画面は
  「解析中」のまま固まる
- Rust / フロント / モックの三者を突き合わせる `npm run check:mock-commands` を追加

実データに対する検証も足した（`src-tauri/src/real_db.rs`）。
実DBの**コピー**に対して走り、DB が無い環境では skip の1行を出して通る。
「コピーを書き換えても元のDBの更新時刻とサイズが変わらないこと」も検証している。
