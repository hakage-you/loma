タグの意味で似ているメディアを探す機能と、タグ整理の機能が入りました。動作の軽量化と安定化も広く入っています。

## 追加

### 似ているメディア（概念スペクトラム検索）

タグの意味をベクトル化して、**タグが完全に一致しなくても内容の近いメディアを探せる**ようにしました。メディアの詳細画面から実行できます。

ベクトル化は自動では走りません。設定 → 詳細設定 →「似ているメディアの検索」から手動で実行してください（解析処理とは別枠です）。埋め込みモデルは3種類から選べます。

### タグ管理・グループ統合

表記ゆれや意味の近いタグをまとめるための画面を作りました。3つの方式で候補を出します。

- **表記ゆれ**: つづり・単複・日本語表記の規則から検出
- **包括語**: AI が「〜の一種である」関係を判定してまとめる
- **意味が近い**: ベクトルの近さで対にする

**出るのは候補であって決定ではありません。** 承認したものだけが統合され、残すタグは候補ごとに選び直せます（手で打ち直すこともできます）。判定は保存されるので、途中で閉じても続きから再開できます。

### 解析失敗の仕分け

解析に失敗したファイルを一覧して、原因の種類ごとに仕分けできるようにしました。解析対象から外す、やり直す、といった操作がまとめて行えます。

### 外部LLMのモデル欄とAPIキー欄

Gemini / OpenAI / Claude を使う場合に、モデル名と API キーを設定画面から指定できるようにしました。API キーは OS の資格情報ストアに保存します（設定ファイルやデータベースには書きません）。

保存済みのキーを読み出せなかったときは、**空欄のまま保存してもキーが消えない**ようにしています。

## 主な修正

### 透過画像に「黒背景」タグが付く問題を修正

透過画像を解析するとき、透明部分を捨てて黒として扱っていたため、**63%のケースで「黒背景」タグが付いていました**。市松模様に合成してから送るようにして、これが出なくなりました。

### 画像の単体再解析が必ず失敗する問題を修正

詳細画面からの再解析が、画像では常に失敗していました。

### 詳細画面でタグを足しても画面に反映されない問題を修正

### 同期ボタンを押しても11秒間なにも起きない問題を修正

押してから最初の進捗が出るまで、進捗もキャンセルボタンも出ていませんでした。押した瞬間から「いまフォルダを探している」ことが出るようにし、探索の途中でも中止できるようにしました。

### 解析中にギャラリーが更新されない問題を修正

解析の進捗が速いと、一覧の取り直しが一度も走らないことがありました。
