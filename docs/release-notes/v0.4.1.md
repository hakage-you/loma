アプリの機能に変更はありません。ライセンス表記と配布物の整備のみのリリースです。

## 配布形式の変更

**配布物を ZIP に変更しました。** `loma_0.4.1_x64-setup.zip` を展開してインストーラを実行してください。

MIT ライセンスは著作権表示と条文を配布物に同梱することを条件としていますが、これまでインストーラ単体を配布しており条件を満たしていませんでした。ZIP には `LICENSE` と `README.md` を同梱しています。あわせて、インストーラ自体にもライセンス同意画面が表示されるようになりました。

過去バージョン (v0.2.0 / v0.2.1 / v0.3.0 / v0.4.0) の配布物は同じ理由で削除しました。リリースノートは残してあります。

## 修正

- 実行ファイルとインストーラのプロパティに**著作権表示が入っていませんでした**。`© 2026 hakage-you` が入るようになっています。
- 著作権者の表記が `@hakageyou` と `hakage-you` で揺れていたため、`hakage-you` に統一しました。
- パッケージ情報の説明文が雛形既定の `A Tauri App` のままだったので、`Local Ollama Media Analyzer` に修正しました。
- ロケールファイルに使われていないバージョン番号がハードコードされ、2 リリース分古いまま残っていたので削除しました。アプリ内のバージョン表示には影響しません（`package.json` から取得しているため）。

## 開発者向け

- リリース手順を [`docs/release.md`](../release.md) にまとめました。
- バージョン番号の管理箇所を `package.json` に一本化しました。`tauri.conf.json` はそこから継承します。
- `package.json` と `Cargo.toml` に `license` フィールドを追加しました。
