# Loma (Local Ollama Media Analyzer)

Loma は、ローカル VLM (画像解析用大規模言語モデル) を用いて、PC内の画像・動画メディアを自動的に解析・自動タグ付け・カテゴリ分類・高速検索できるデスクトップアプリケーションです。

大切な写真などのプライバシー保護のため、3Dゲームが動かせる程度のスペックのPCがあればAIの学習などに利用されずに分析・分類ができるように作りました。<br>
(非サポートですが、API keyを設定することでクラウドのVLMを利用した解析も可能です。)

※コードを書く部分についてはすべて生成AIにやってもらってます。

## 1. 概要

- **🤖 ローカル VLM 自動タグ付け**:
  - ローカルで動作する Ollama VLM と連携し、完全オフライン環境で安全にメディアを解析します。
  - 画像（PNG, JPG, WebP, BMP）および動画（FFmpeg連携によるフレーム抽出）を自動解析。
  - 分類結果に基づいて、事前に用意してあるカテゴリ分類と、画像ごとに複数のタグを自動で付与を実行します。
  - モデル規模（10Bパラメータ基準）に応じた最適プロンプト（`DETAILED`(高精度) / `LIGHT`(省メモリ)）の動的切替を行うため、VRAMの少ないGPUでも動作する想定です。高精度の方が適切かつ多くのタグ付けができるので楽しいと思います。

- **🎛️ フィルタ機能**:
  - カテゴリやファイルの種類ごとに表示をフィルタリングすることで特定の条件に合致するメディアを抽出できます。

- **🔍 タグ検索機能**:
  - 同じタグが付与されたメディアを検索、一覧することで意外な繋がりをもつ写真たちを発見することができるはずです。

- **🧭 似ているメディアの検索（概念スペクトラム）**:
  - タグの意味をベクトル化することで、**タグが完全一致しなくても意味的に近いメディア**を探せます。「猫」の写真から「うさぎ」の写真が出てくるような、タグ検索では辿り着けない繋がりが見つかります。
  - **基準とタグを共有するメディアは候補から外します。** それらはタグ検索で見つかるため、この画面では「タグが違うのに意味が近い」ものだけを出します（「缶」から「ビール缶」ではなく「サバ缶」が出る、という考え方です）。
  - 「タグは違うが意味が近い」「中くらい」「意味が最も遠い」の3つを同時に出し、🎯 ボタンで**そのメディアを新しい起点にして探索を続けられます**。意外な写真に行き当たるための機能です。
  - 類似度は生の数値とレンジ凡例で開示するので、「なんとなく似ている」ではなく**どれくらい似ているか**が分かります。
  - ベクトル化は設定画面から手動で実行します。スキャンや解析の動作には一切影響しません。

- **🔗 タグマージ機能**:
  - VLMにより自動で付与されるタグには微々たるゆらぎがあるため、似た意味を持つタグが複数登録されてしまうことがあります。タグマージ機能により、意味の似通ったタグを自動検出し、マージを行うことでタグによる検索性を向上させることができます。
  - AIの解析によって類似したタグを自動で検出し、統合を提案します。これも意思を持って特別の設定をしないかぎりクラウドにデータが送信されることはありません。

## 2. 動作環境のセットアップ

### 2.1. ollamaのインストールとセットアップ

1. 公式サイトからollamaをダウンロードしてインストールする

   Ollamaで検索して！リンク切れ対応とか面倒なのでリンクは貼りません。ごめんね！

2. Ollama にVLMを追加する

   `qwen3-vl` `gemma4` などの vision対応モデルをOllamaに追加する。 コマンド例: `ollama run qwen3-vl` 
   
   **ここに書かれている意味がわからない場合はオススメVLMをインストールする機能があるためこの手順は無視してください。**

### 2.2. (Option) FFmpegのインストールとセットアップ

※動画の解析をしたい人だけやってください。

1. 公式サイトからFFmpegをダウンロードしてインストールする

   これもリンク切れ対応とか面倒なので検索して！ほんまごめん。

## 3. 使用方法

Loma の基本的な使い方は次の3ステップです。

1. **① 設定でモデルを選ぶ** → 2. **② フォルダを追加してスキャン** → 3. **③ タグやカテゴリで絞り込んで閲覧**

スクリーンショット付きの詳しい手順は [使用方法ガイド](docs/usage.md) を参照してください。

## 4. ビルドおよび開発手順

### 4.1 前提条件

アプリのビルドおよび動作には以下のツールが必要です。

1. **[Node.js](https://nodejs.org/)**: v20.19 以上（v22.12 以上推奨）
2. **[Rust](https://www.rust-lang.org/)**: Cargo 1.75 以上推奨
3. **[Ollama](https://ollama.com/)**:
   - ローカル環境で Ollama サービスが起動していること (`http://localhost:11434`)。
   - Vision 対応モデル（例: `qwen3-vl`, `llava`）がダウンロードされていること。
4. **FFmpeg** *(任意)*:
   - 動画ファイル（`.mp4`, `.mkv`, `.mov` 等）のフレーム抽出・解析を行う場合は必要です。未インストールの場合は動画処理が自動的にスキップされます。

### 4.2 ビルド・利用方法

#### 1. 依存関係のインストール

```bash
npm install
```

#### 2. 開発サーバーの起動 (Dev Mode)

```bash
npm run tauri dev
```

#### 3. プロダクションビルド (Executable & Installer)

```bash
npm run tauri build
```
ビルド完了後、実行ファイルおよびインストーラが `src-tauri/target/release/bundle/` 配下に生成されます。

#### 4. テストおよび動作チェック

```bash
# フロントエンド TypeScript チェック
npm run build

# バックエンド Rust チェック
cd src-tauri
cargo check
cargo test

# UI テスト (Playwright / 初回のみ npx playwright install chromium)
npm run test:e2e
```

### 4.4 VLM 連携の知見

VLM 連携で踏んだ落とし穴と実測データは [VLM 連携の知見](docs/vlm-notes.md) にまとめてあります。
解析プロンプトを変更する場合は、事前に目を通したうえで
[`tools/prompt-check/`](tools/prompt-check/README.md) の回帰チェックを回してください。

### 4.5 計測ハーネス

LLM が絡む部分は「良くしたつもり」で静かに壊れるため、実データで測るツールを用意してあります。
いずれも**本番と同じコード**を通すよう作ってあり、計測用の再実装は持ちません。

| ツール | 用途 |
|---|---|
| [`tools/prompt-check/`](tools/prompt-check/README.md) | 解析プロンプトの回帰チェック（タグ本数・パース失敗率・空応答率） |
| [`tools/embedding-check/`](tools/embedding-check/README.md) | 埋め込みモデルの比較（類似度分布・ハブ化・上位/中位/下位の実例） |
